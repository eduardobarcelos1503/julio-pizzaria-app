# Julio's Pizza Perfect

Crie um site profissional, moderno e altamente focado em conversão para a Julio Pizzaria, uma pizzaria de delivery localizada em São José dos Pinhais - PR.

OBJETIVO PRINCIPAL

O site deve funcionar como uma vitrine profissional da pizzaria e, principalmente, incentivar o cliente a fazer o pedido pelo WhatsApp.

A pizzaria possui uma excelente reputação no Google, com nota 4,9/5 baseada em 62 avaliações, então isso deve ser utilizado como uma das principais provas sociais do site.

O design deve transmitir:

Pizza artesanal e saborosa

Qualidade

Recheio generoso

Atendimento próximo

Entrega rápida

Confiança

Sensação de pizzaria local e familiar

Vontade de pedir uma pizza imediatamente

Não quero um site genérico de pizzaria. Quero algo com aparência de um negócio real, profissional e pronto para receber pedidos.
